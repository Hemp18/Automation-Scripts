These are automation scripts for a few Roblox games. I wanted to start with Roblox due to the wide variety of games. 

What did I learn?
I learned how to give Python the ability to take my PC over and handle mundane tasks in these games. I faced some difficulties and needed work arounds, but overcame them.

What are the limitations?
As shown in the code, these scripts rely on fixed coordinates to work. If the game crashes or I'm disconnected, the program doesn't have the "eyes" needed to realise that and stop, it'll run endlessly until I use the "q" hotkey to stop the program.
